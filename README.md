# Magnetic criticality analysis revision 0.2

Both the GUI and command-line interface call `critical_engine.run_pipeline`. This revision replaces the self-normalised bin loss with prediction of held-out isotherms, keeps temperature branches separate and records numerical failures and review flags.

## Install and run

Python 3.12 is the tested interpreter. The exact local test environment is recorded in `requirements-tested.txt`; other interpreter/package combinations are not claimed as tested.

```sh
python -m pip install -r requirements.txt
python -m pip install -r requirements-optional.txt
python analysis_cli.py --data "data/*.csv" --field-unit Oe --reversible --auto-cutoff --out out
python GUI_Final_v2_kferr_FIXED_v26.py
python -m pytest tests -q
```

Existing launcher filenames remain available. Some optional APIs have changed; the original implementation remains available in the base Git history.

Field units come from headers or an explicit argument. Supported physical inputs are T, mT, Oe, kOe and A/m. Cutoffs are in tesla after conversion. An explicitly declared `relative` field scale permits dimensionless diagnostics but cannot produce absolute Maxwell entropy. `--bc` is a compatibility alias for `--h-min`, not a magnetisation background or an internal-field coefficient.

`--reversible` records an applicability assumption about the selected measurements. The program cannot establish equilibrium or sample phase composition from a positive-field file alone. Sweep reversals require `--branch ascending` or `--branch descending`, with one cycle per input file. Unordered digitised curves require the explicit configuration `ordered_sweep: false`.

## Synthetic example

All curves generated by this example are synthetic. The toy mean-field model assigns a 1 T reference field and a 1 A m2/kg reference magnetisation, with a prescribed transition at 100 K.

```sh
python examples/generate_mean_field.py --out examples/generated
python analysis_cli.py --data "examples/generated/*.csv" --reversible --tc-fixed 100 --init-beta 0.5 --init-gamma 1 --out out/example
```

To reproduce the larger controlled checks:

```sh
python benchmark_synthetic.py --out benchmarks/generated --replicates 12
python sampling_study.py --out benchmarks/sampling --bootstrap 80 --steps 4000
```

The recorded benchmark contains 100 fits over four prescribed exponent pairs, known Tc and independent multiplicative noise. It is a controlled recovery check, not a validation of arbitrary materials, initial states or noise models. The 80-replicate sampling study is a preview; it does not establish interval coverage. Recorded scalar synthetic summaries are included under `benchmarks/generated`.

## Scientific behaviour

- Collapse uses dimensionless logarithmic coordinates with separate branches. Predictions use other distinct temperatures on the same branch and never extrapolate. Every target requires at least six predicted points and 35% supported points. A curve cannot validate itself.
- High-field windows use normalised alternating-point cross-validation plus disclosed support/extrapolation penalties. Cutoff selection uses a dimensionless criterion. Intercepts are not forced towards zero at every temperature.
- KF side availability, convergence, fallback temperature candidates and the final fixed-Tc refinement are saved. Preferred universality classes do not define reliability gates.
- Results distinguish `success`, `review_required` and `failed`. A numerical success remains conditional on the supplied physical assumptions.
- Conditional and full-pipeline resampling are distinct. Failed/review-required replicates, joint samples and quantile stability diagnostics are retained. No temperature-grid fraction is inserted as an uncertainty estimate.
- Loss-based chains support fixed or joint Tc and save four starts, bounds, loss temperature, traces, acceptance, split R-hat and autocorrelation ESS. They are sensitivity distributions, not calibrated measurement posteriors.
- Universality compatibility requires a nonsingular joint covariance and can be indeterminate or not applicable. It is a heuristic diagnostic, not a class probability.
- GP fits are descriptive branch curves at final physical parameters. GP exponent posterior sampling and the joint objective combining magnetisation with its correlated derived MCE are disabled.
- EOS diagnostics predict fields directly through the Arrott-Noakes form on a fixed point set. `log_field_mse` is not reduced chi-square. Predictions, residuals, point counts and invalid predictions are recorded.
- Maxwell integration uses unique temperatures, confirmed physical units and the common measured field interval. Missing low-field contributions are flagged. No loop folding or silent extrapolation is performed.

`background.py` estimates a linear contribution from an independent blank. The field-correction helper instead requires an independently supplied coefficient for internal field. These are separate operations from low-field exclusion.

## Provenance and validation

Runs save configurations, source-file hashes, input hashes, environment, fitting windows, objective support and state history. JSON output serialises arrays and converts nonfinite quantities to null.

The local scientific regression suite contains 23 passing tests. GUI startup, a complete file-based CLI example and optional GP/EOS/MCE paths were also exercised locally. The workflow under `.github/workflows` runs the scientific tests on Windows with Python 3.12; its remote status must be checked independently.

This public change contains software, tests and synthetic examples. Experimental measurements, material reanalysis summaries, manuscript files and research review reports are distributed separately and are not part of this public change.
